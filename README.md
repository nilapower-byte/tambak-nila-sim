# Tambak Nila Sim

Game simulasi budidaya ikan nila 3D (Three.js). Bangun kolam terpal atau kolam tanah, alirkan air, tebar benih, beri pakan, jaga oksigen dan amonia, lalu panen. Kondisinya meniru kenyataan: cuaca harian, listrik padam, penyakit, dan harga jual yang naik-turun.

Satu file statis: `index.html`. Tidak ada proses build.

## Hosting di Cloudflare Pages

Workers & Pages → Create → Pages → Connect to Git → pilih repo ini.
- Build command: (kosong)
- Build output directory: `/`
